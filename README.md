# Junteng Liu - Homepage

Personal academic homepage of Junteng Liu, built using the [Academic Pages template](https://github.com/academicpages/academicpages.github.io).

## Structure

- `_pages/about.md` - Main page with personal details, academic background, research experience, publications, skills, and contact information
- `_publications/` - Individual publication pages
- `_config.yml` - Site configuration
